# EFi_PP1_Python

## Temática

La temática elegida para el trabajo integrador final corresponde al sistema de una concesionaria automotriz de alta gama bajo el nombre comercial Alboriena Motors.

## API y Arquitectura

API REST desarrollada con FastAPI y SQLModel, conectada a una base de datos SQLite y gestionada mediante migraciones con Alembic. Desplegada en FastAPI Cloud.

## Estructura de Tablas

* Pais
* TipoVehiculo
* Marca
* Vehiculo
